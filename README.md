# Encryption & Decryption Lab

## Overview
Hands-on cybersecurity lab using Linux command-line tools to work with encrypted data and recover plaintext using a classical cipher.

## Skills Demonstrated
- Linux command-line operations
- File management
- Encryption and decryption
- Basic cryptography
- Data security

## Key Takeaway
Strengthened my understanding of how encryption protects information and how decryption can restore protected data for authorized use or investigation.
